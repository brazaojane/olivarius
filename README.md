# Olivarius

Site fictício de serviços de desenvolvimento de software, em HTML, CSS e JavaScript puro.

## Rodar localmente

Só abrir o `index.html` no navegador, ou usar uma extensão tipo Live Server no VS Code.

## Estrutura

```
olivarius-html/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```
